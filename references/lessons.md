# 踩坑清单（lessons.md）

每一条都是真实翻车后总结的，含原因。新期生产前扫一遍，尤其第 1、2 条。

## 1. TTS 发音与分词（最高频翻车点）

合成完**必须**检查词级 JSON 的 `timestamped_words` 序列，四种已知陷阱：

| 陷阱 | 症状 | 解法 |
|---|---|---|
| 英文专名逐字母拼读 | `K\|i\|ro`、`C\|rew`、`G\|it\|H\|ub` | 优先改文本写法（连写、加中文注音引导），读音无法保证就换措辞 |
| 中文音译字典 | 用户听感差（"GitHub/吉特哈布"被明确否决） | **英文一律读英文原音，禁用中文字音译目标** |
| pinyin 发音字典 | 单字被拆成多个 token，字幕出"长长长长" | 发音字典只用**中文字目标**（"55GB/五十五个G"）；用了 pinyin 必须自检字幕文本 |
| 阿拉伯数字 + 量词 | `11\|11` 重复 token（"11月12号"） | 口播里的日期/数量**直接写中文数字**（"十一月十二号""一千两百个"） |

多音字自检清单：`长`（长任务 cháng）、`重`、`数`、`行`、`差`、`得`、`还`。命中就加发音条目（中文字目标）。build 时间轴后 grep 输出，确认无重复 token、无纯标点伪影。

## 2. 渲染后"假死"静帧（最隐蔽）

`chai_check_motion` 用**全帧平均像素差**（阈值约 1.2/255）判定静帧。低对比度皮肤（如 Neumorphism 同色系卡片）上的微幅缩放/浮动，像素差低于阈值 → 开场被判 0.8–3.5s"动效冻结"FAIL，实测迭代 4 轮才过。

**预防模板**（F1 场景前 2 秒动效链，渲染前先自检）：

```
0.15s  kicker/chip 入场（大幅 y 位移）
0.55s  卡片回弹脉冲（scale 1.015, 0.3s）
0.7–0.95s  主标题大字入场（112px 级别的大字位移必过阈值）
1.0s   大序号透明度脉冲（.72 ↔ 1，高对比元素）
之后    浮动 yoyo 循环（幅度 ≥5px 或作用在高对比元素上）
```

原则：**前 1.2 秒内至少有一个高对比、大尺寸元素在大幅运动**。同色卡片上的小动作不算数。

## 3. 安全区是契约，评审会发现"假越界"

- 字幕/头像有**专用带区**（speechBar：top 1488，height 114 → 底边 1602），不要用通用内容安全区线（y=1560）去判它越界——评审 subagent 犯过这个错。
- 口播栏（头像 + 字幕）之外**不加任何常驻元素**。加过一次"柴主编"名牌（bottom:-30 伸到 y≈1626），被评审抓出来，而且回查发现历史所有成片名牌都是隐藏的——先例也是契约。
- 画面内容止于内容安全区；序号、注记的位置每期一致。

## 4. 排版溢出速算

- 大标题宽度 ≈ 字数 × 字号 × 0.95（CJK）。`这次写进官方名单的，` 10 字 × 122px ≈ 1220px > 860px 内容宽 → **溢出画面右缘**。改短行（"这次上榜的，"）。
- 孤字折行是 P1：`加算/力`、`换/模型`、`模型 A / B /`+`C`。修法：缩字号一档（34→30）、改写（`A/B/C` 去空格）、或加宽容器。
- 日期 `2026-08-27` 在窄卡里会从连字符断行（`2026-`/`08-27`）→ 缩字号（26→22px）或拆两段排。
- 注记行折行别把右括号甩到行首 → 缩短文案而不是缩字号。

## 5. 评审结论要甄别，不全盘照收

真实案例：3 条 P0 里 2 条是误报（越界判定用错了契约线、字幕组内两行折行是 workflow 明文许可路径）。流程：**逐条核对评审引用的"契约原文"再动手**；真问题马上修（那次真问题是铭牌越界），误报写进 quality-report 的甄别记录。

已知误报模式（写进评审 prompt 的豁免条款可预防）：

- 转场帧瞬态交叠、入场半透明
- 模型知识截止 → 把当天/过去日期判成"未来日期"
- coined 表达被当语病（"上黑客榜"）
- 仓库名里的数字 0 被当错字（`jub0t`）

## 6. 工程与渲染纪律

- HyperFrames CLI 版本 **pin 在工程 package.json**（如 `hyperframes@0.7.102`），升级是专项任务：`upgrade` → `check` 通过才留，失败回退 pin。
- **不要并行渲染**两个工程：headless Chrome 启动会互抢资源随机失败（实测两次）。顺序渲染，一期约 1 分钟。
- 每期工程从上一期 `cp -R` 克隆（皮肤/几何零改动，只换内容与文案），这是"复刻速度"的关键；皮肤规格沉淀在工程 `frame.md`。
- `check` 的对比度告警全清再渲染：弱灰文字按 checker 建议值加深（#8A94A8 → #666D7C 级别），大序号刻印字用 #7D8686 起步。

## 7. 内容安全红线

- 客户端免费 ≠ 模型免费：开源工具的 API 用量按厂商计费，置顶评论注明。
- 不点名攻击竞品；对比只讲"形态差别"（单会话 vs 常驻）。
- 安全类内容不渲染"AI 失控"，行动建议克制且标注"非事实断言"。
- 引流红线：GitHub 仓库/官网即软件本体可以说，其他站外引流不行。
