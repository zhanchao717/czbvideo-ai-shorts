# 设计系统（design-system.md）

两套已验证的皮肤 + 版式契约。品牌骨架跨期一致，主题强调色随选题变化，避免"同一张模板换字"的感觉。

## 版式契约（1080×1920，坐标即法律）

```
内容安全区      左右 72 / 上 120 / 下 360（帧内容止于 y≈1380）
来源注记带      y 1380–1490（SOURCE 行，left 110）
口播头像        left 190 / top 1490 / 110×110（圆环包住）
字幕带          left 326 / right 156 / top 1488 / height 114
```

- 字幕组超宽时**在组内折行**（许可路径），不缩字号、不动带区坐标
- 字幕文本与 `caption_groups.json` **逐字节一致**（折行不增删字符）
- 口播头像嘴型：由词级时间轴驱动开合（attack 0.07s / release 0.09s / 音节波 18.5rad/s），句间停顿闭嘴
- 头像名牌默认隐藏（先例即契约）

## 皮肤 A：Cobalt Grid（蓝网格报版）

钴蓝 `#1F2BE0` + 纸白 `#F0EBDE`，方角、细线、graph-paper 网格底，mono 标签。适合硬新闻、数据型选题。字幕：方角卡片 + 钴蓝色块压当前词（risograph 套印感）。

## 皮肤 B：Neumorphism「Soft Slate」（新拟物）

同色系冷灰蓝，靠双向柔影成形——注意配合 lessons.md §2 的动效模板使用。

```
背景      linear-gradient(160deg, #EDF1F8, #E2E7F1)
卡片底    linear-gradient(145deg, #EDF1F8, #DDE3EE)
浮起 raised   box-shadow: 16px 16px 32px rgba(146,158,180,.55),
                     -16px -16px 32px rgba(255,255,255,.95);  圆角 36px
凹陷 inset    box-shadow: inset 9px 9px 18px rgba(146,158,180,.5),
                        inset -9px -9px 18px rgba(255,255,255,.95); 圆角 28–36px
墨色      主 #33415C / 重 #26334D / 弱 #5C6B85（对比度达标下限）
强调色    #D94800（全片 ≤3 处：钩子句、行动句、封面主题字）
大序号    刻印效果：color:#7D8686 + text-shadow 双向柔影
字体      无衬线展示体（CobaltSans / 系统黑体），不用衬线
字幕      凹陷药丸承托 + 当前词"浮起软芯片"卡拉OK（upcoming 半沉 / spoken 实墨）
```

### 五个场景模板（对比/数据/机制/行动/判词）

1. **钩子**：内凹警示条（或 kicker 芯片）+ 两行大字（强调色在结果词）+ 浮起答案卡
2. **事实**：2–3 张浮起数据卡（大数字 + 标题 + 口径注脚），口播念到时数字脉动 1.04
3. **机制**：流程三节点（浮起卡 + 箭头）或三口凹陷井（01/02/03 圆片），随口播逐个入场 + 上浮 9px 打点
4. **行动**：三口井或大按钮（按压动效：scale .965 → back.out 弹起）+ 平台芯片
5. **判词**：刻印大字两行 + 浮起结论卡（强调色行动句）+「本期观点」标注

所有入场：`fromTo(y:44–60, opacity:0 → 0,1, power3.out 0.6–0.7s)`；环境动效：y ±5px sine yoyo；转场：0.5s 交叉淡化 + y∓14/scale .985（**不用**横滑）。

## 三比例封面（独立排版，禁止裁切拉伸）

同一套标题组逐字出现在三个比例：

```
kicker 芯片（主题一句话）
主标题两行（第二行强调色）
行动胶囊（GitHub 搜 XXX / 一句行动）
品牌行「柴主编｜只讲一件事」+ 大期号
```

- 9:16（1080×1920）：主卡竖置居中，大留白
- 3:4（1080×1440）：主卡收紧，元素同序
- 4:3（1440×1080）：左文右卡分栏，右卡可加信息行（仓库名/信源+日期）

用无头浏览器对 `cover.html` 按 viewport 截三张（参考工程 scripts/render-covers.mjs）。字号在 4:3 版通常要降一档防断词。

## 渲染配置

1080×1920 @30fps · H.264 + AAC · 总时长按档位 25–45s。HyperFrames 工程 `package.json` pin 死 CLI 版本。
