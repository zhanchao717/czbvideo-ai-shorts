# 选题与调研（research.md）

## 调研渠道（agent-reach 或等效工具）

- **全网新闻**：Exa 网页搜索（中英文各一遍，覆盖当天 + 近 3 天）
- **GitHub 新工具**：`gh search repos "created:>=<近7天> stars:>=100" --sort stars`——免费工具线的富矿
- **官方一手**：GitHub API（license/star/创建日期）、官方博客（Jina Reader 抓全文）、官方 JSON feed（如 CISA KEV 漏洞目录——报道不可信时直查源头）
- **时效判断**：可靠媒体的报道日期超过 72 小时 → 降级或弃用；只有内容农场可源的"爆点"直接弃

## 落选也要记录

sources.md 末尾维护「落选备选」：一句话理由（旧闻 / 无可执行动作 / 与近期主题同质）。防止三天后重复调研同一个坑。

## 一天多期的不同质检查

- 支柱不同（免费工具 vs 教程 vs 行动型热点），或
- 同支柱不同角度（事件 vs 解法；硬件 vs 软件）
- 钩子四类（结果/避坑/对比/问题）连续两期不重复
- 同一产品/模型最多 2 期，第二期必须换角度（实操、算账、边界）

```markdown
## 事实清单（每条：结论 + 来源URL + 定性）

   - <URL>
   - 定性：**可证事实** / **官方自述** / **XX 口径** / **媒体解读**。

## 编辑判断与禁项

- 本期不说：<清单>
- 免费口径：<客户端免费 ≠ 模型用量免费> 等边界声明
- 候选评分：<分项> = **XX/100 ≥ 70，生产**

```

## 评分锚点示例（供校准）

- 88 分：断供事件避坑（多源实锤 + 强可执行 + 系列承接）
- 87 分：大厂开源代理工作台（官方口径充分 + 教程支柱）
- 86 分：新开源剪辑工具（官方自述未实测 + 快速档）
- 6X 分：安全联名信（宏观警示，当天无可执行动作）——不生产
